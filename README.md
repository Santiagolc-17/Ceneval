# Preguntados Chill (React + Vite)

Juego de trivia visual tipo Preguntados, hecho con **React + Vite**.

## Requisitos

- Node.js 18+
- npm 9+

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev -- --host 0.0.0.0 --port 4173
```

Abre: `http://localhost:4173`

## Build de producción

```bash
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

## Qué incluye

- 100 preguntas en español.
- 4 opciones por pregunta.
- Retroalimentación inmediata (correcta/incorrecta + explicación).
- Puntaje en vivo y resultado final.
- UI moderna estilo glassmorphism.
