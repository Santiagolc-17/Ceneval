# Preguntados Chill (100 preguntas)

Mini juego web estilo trivia, visual y relajado, hecho con **HTML + CSS + JavaScript**.

## Cómo correrlo

```bash
python3 -m http.server 8000
```

Luego abre: `http://localhost:8000`

## Qué incluye

- 100 preguntas mezcladas automáticamente.
- 4 opciones por pregunta.
- Retroalimentación inmediata cuando fallas (muestra respuesta correcta + explicación).
- Puntaje en vivo y resumen final con nivel.
- Diseño tipo glassmorphism con gradientes.

## Instrucciones/prompt para Codex (si quieres extenderlo)

Copia y pega esto en Codex:

```text
Quiero mejorar mi juego de trivia web (HTML/CSS/JS) con estas reglas:
1) Mantén un estilo visual moderno (glassmorphism, gradientes, animaciones suaves).
2) Conserva 100 preguntas en español.
3) Añade selector de dificultad (fácil/medio/difícil).
4) Agrega cronómetro por pregunta (15s) y resta puntos si se acaba el tiempo.
5) Guarda récord local con localStorage.
6) Añade botón "Revisar errores" al final para ver solo las que fallé.
7) No uses frameworks, solo HTML/CSS/JS puro.
8) Entrega código completo por archivos: index.html, styles.css y app.js.
```
